# HabitNote

Personal habit-tracking Android app using Jetpack Compose and Room for local storage.

## What I built

- Habit list / tracking UI in Compose
- Local persistence with Room
- ViewModel-style state handling

Portfolio / learning project (`com.example.habitnote`).

## Stack

Kotlin · Jetpack Compose · Material 3 · Room (KSP) · Navigation Compose · Coroutines

## Run locally

```bash
git clone https://github.com/Pathrinarayanan/habitnote.git
cd habitnote
```

Open in Android Studio, sync, run (API 24+).

```bash
./gradlew :app:assembleDebug
```
